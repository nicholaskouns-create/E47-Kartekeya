Levinthal’s paradox, resolved by spectral depth

Levinthal counted configurations and found folding times longer than the age of the universe. The depth law counts something else, the steps a contraction needs, and the number of configurations never appears in it.

Blind enumeration is the research note’s toy count: b = 9 states per residue, one per τ₀ = 10⁻¹³ s. Spectral depth is the step count of the convex funnel in §3 at δ = 10⁻⁶ for a chain of the same length. That funnel is a 2D Gō model, so a preset fixes N only.

PRIMA FACIE

The resolution in four lines

  1. Tblind = |Σ| · τ₀, |Σ| = bᴺLevinthal’s premise: folding by enumeration. At b = 9, N = 100 and τ₀ = 10⁻¹³ s this is 2.66 × 10⁸² s.
  2. D(δ) = ⌈ln(1/δ) / ln(1/q∗)⌉, q∗ = (ℛ − 1)/(ℛ + 1)The depth law for Ψₙ₊₁ = ΛΨₙ with Λ = I − ε∗A. It is sharp in both directions, ½(ℛ − 1)·ln(1/δ) ≤ D(δ) ≤ ⌈½(ℛ + 1)·ln(1/δ)⌉, and nothing in it depends on |Σ|.
  3. blind search: ℛ ~ |Σ| · funnel: ℛ = poly(N)Enumeration is the landscape whose spectral spread grows like the configuration count. A funnel’s spread grows polynomially: the convex funnel below has ℛ = 218.6 at N = 100.
  4. Exponential configuration space ≠ exponential convergence depth.The paradox assumed the first forces the second. For the fixed-step law, depth is exponential exactly when ℛ is.

§2 · THE THEOREM

Depth is spectral

Near its target x∗, a constrained objective Γ = Gₛ + κ‖Fₛ‖²/2 steps by Λ = I − ε∗Aₛ, with Kₛ = DFₛ(x∗) and Aₛ = Kₛ†Kₛ. The theorem counts the steps.

Λ = I − ε∗Aₛ, ε∗ = 2/(λₘₐₓ + λₘᵢₙ⁺)
‖Λⁿ − P‖ = q∗ⁿ, q∗ = (ℛ − 1)/(ℛ + 1), ℛ = λₘₐₓ/λₘᵢₙ⁺
D(δ) = ⌈ln(1/δ) / ln(1/q∗)⌉
½(ℛ − 1)·ln(1/δ) ≤ D(δ) ≤ ⌈½(ℛ + 1)·ln(1/δ)⌉

The dimension of the space, and the number of configurations in it, appear nowhere. Because the bound is attained, a fast fixed-step fold needs a small ℛ and nothing else.

E₄₇’s K has eigenvalues of both signs, so its contraction needs A = K². A residue-graph Laplacian with non-negative weights already satisfies L ⪰ 0, so A = L reaches the same kernel with spread ℛ. Using A = L², the form of InvariFold’s Γ = I − εL², gives the same kernel with spread ℛ². §3 switches between them.

Each curve is an exact computation in its own model. Blind enumeration is bᴺ. §6 · BOUNDARY

What this establishes

Levinthal’s estimate equates folding time with |Σ|·τ₀. The depth law sets the step count by ℛ, and blind search is the case ℛ ~ |Σ|. Any landscape whose spread grows sub-exponentially in N folds in sub-exponential depth. This is a sufficient-condition resolution of the combinatorial paradox, not a proof of global molecular convergence.

Not claimed

  • That a real force field is globally convex. Real landscapes are nonlinear and have barriers; the theorem applies near a regular point and on convex basins.
  • An operator, or a value of ℛ, for any specific protein. The 2D Gō fold is a model, and the presets set N only.
  • A 47-dimensional molecular kernel or a biological 0.376 threshold.

Open

Measure ℛ for real proteins: build Markov state models for a family of increasing length, take the nonzero spectrum of each rate matrix, and fit ℛ(N).
