Hodge residuals are computed from explicit oriented boundary matrices. The edge space is padded to all 190 possible edges to compare changing complexes. Hash inputs use deterministic UTF-8 JSON serialization and a nonce. Results are local calculations, not independent experimental validation or quantum-hardware results.

First-principles derivation and limitations

For a finite simplicial complex, Δ₁ = B₁ᵀB₁ + B₂B₂ᵀ is positive semidefinite; ker(Δ₁) = ker(B₁) ∩ ker(B₂ᵀ). Hodge decomposition identifies its kernel with H₁ over ℝ. With 20 vertices, 20 edges, and no triangles, Euler–Poincaré gives β₀−β₁ = 0, hence β₁=β₀. β₁=0 is possible at other radii when edges and triangles change.

For nonzero eigenvalues λ of Δ₁, Γ = I−ηΔ₁ contracts when 0<η<2/λmax. Choosing η=2/(λmin⁺+λmax) minimizes the maximum contraction magnitude. Its n-fold operator-norm residual is ρⁿ. For an empty edge space or zero Laplacian, the projector already equals the identity on C₁.

The unitary simulation Q(s)=exp(−isΔ₁) fixes ker(Δ₁) exactly by functional calculus. This is an algebraic model; no hardware experiment is represented. A cryptographic seal establishes binding to bytes given an unguessable nonce, not independently predictive skill. The persistence forecast is a baseline and can fail during topology transitions.
