Prior authorization worksheet

Public coding references do not establish medical necessity or payer authorization. Verify the patient's actual policy, current payer criteria, diagnosis-to-service coverage, network, and documentation requirements. Never enter PHI in a public repository.

Billing and authorization references

Anesthesia-specific coding

For anesthesia reimbursement, validate ASA anesthesia code (00100–01999), physical status modifier, applicable qualifying circumstance codes, base units, documented time, modifiers and payer-specific conversion factor. Medicare uses locality and other adjustments; a generic CPT fee is not the anesthesia allowance. ASA relative-value and descriptions may require licensing.

Medicare RVUs and payments

The CMS Physician Fee Schedule files supply status indicators and RVUs; exact payment depends on date, locality, facility setting, geographic adjustments, modifiers and payer. No dollar estimate is shown until a relevant verified fee pack is loaded.

Procedure and diagnosis pairing

A diagnosis and procedure appearing together does not prove coverage. Review payer medical policy, applicable Medicare NCD/LCD, NCCI PTP edits and MUEs. Use CMS source links below.

Privacy

This static site does not send worksheet input to any server and does not persist worksheet details. Imported code-pack data are held in browser memory. Do not put patient identifiers into the app; use a HIPAA-appropriate clinical system to process PHI.
