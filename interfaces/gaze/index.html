Coordinate conventions & computation

Browser engine: Astronomy Engine 2.1.19. Topocentric true-equator-of-date coordinates with precession, nutation and aberration; atmospheric refraction off. Azimuth runs clockwise from true north. Radius = 90° − altitude. Stars use the supplied fixed J2000 catalog, with no proper motion and negligible parallax. Below-horizon targets remain in the numeric list. Elevation is the observer height above sea level.

This is a computed sky at the selected time, not a live sensor feed. The E47 badge gives the rank fraction 47/125; no sky-to-E47 projector or coherence score is computed. The Python companion uses Astropy’s builtin ERFA ephemeris, not DE430. Browser and Python engines have distinct numerical approximations.
