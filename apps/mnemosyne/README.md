# MNEMOSYNE · Spectral Clock Graph Lab

A classical quantum-inspired temporal graph neural network app, built and locally tested in Python. The full app source bundle is prepared as `Mnemosyne_Spectral_Clock_Graph_Lab.zip` for import; this README does **not** imply its Python and HTML files have been uploaded.

Architecture: 125-dimensional spin-2 tensor carrier, 47-dimensional spectral projector, period-47 real unitary clock on E47, dynamic synthetic graph generation, graph aggregation, recurrent GRU, learned BCE link prediction, held-out-time ROC AUC comparison. The source has four passing automated tests. Initial 32-node, 8-step, 12-epoch synthetic benchmark: baseline AUC 0.54842; E47-clock AUC 0.50383; delta -0.04459. No performance improvement is claimed. Classical quantum-inspired simulation only.

The instrument is named **Mnemosyne** after the figure of memory: reproducibility, continuity, and verifiable traces, not a claim of AI selfhood.
