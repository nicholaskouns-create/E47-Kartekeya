# Research

This directory contains open research lines, theorem notes, candidate constructions, and domain-specific investigations that sit beside the executable software.

## Programs

- [E47](e47/) — spectral core notes, theorem plates, and open proof obligations
- [Stargate](stargate/) — independent research line retained in its own local structure

## Contract

Research directories are intentionally plural.

A result in one program does not automatically promote or invalidate another program. Each line retains its own objects, assumptions, evidence class, failures, and unresolved questions.

Executable implementations belong under `src/` when they become reusable package code. Machine certificates belong under `certificates/`. Public interactive instruments belong under `website/interfaces/`.
