# SAT → Newton → Basin Boundary → Box Dimension

Measured E1 finite-resolution basin geometry. High-resolution mean D = **1.149898**; 192²–512² range **1.135664–1.158807**; robustness band **1.125273–1.158807** under 4/8-neighbor definitions. Run `python sat_newton_boxdim.py --out results.json`.

This is not a polynomial-time algorithm for general SAT.
