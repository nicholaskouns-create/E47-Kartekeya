What this repository is

A research software package that reconstructs and certifies the E47 spectral kernel algebraically. It is not a claim of experimental physics hardware or cosmological discovery — it is executable mathematics with frozen certificates.

SU(2) kernel algebra

Builds spin-2 triple tensor operators, Casimir spectrum, and the selector K = (C − 6I)(C − 30I) with exact kernel dimension 47.

Projector & channel

Constructs the orthogonal projector P₄₇, verifies idempotence, hermiticity, annihilation KP = 0, and discrete dephasing contraction.

Semigroup flow

Validates continuous evolution S(t) = exp(−t K²) and asymptotic convergence onto the E47 subspace.

SU(3) adjoint extension

Additional 512-dimensional adjoint construction with singlet projector and structure-constant tooling in the same package surface.

Install & reproduce

Distribution name e47-kartekeya; import package e47.

# From PyPI
pip install e47-kartekeya

# From a local checkout
pip install -e .
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest tests/ -v

# Regenerate aggregate certificate
python scripts/generate_validation_certificate.py

# Compile spectral kernel passport
python scripts/compile_spectral_kernel.py --spin 2 --copies 3 --select 2 5
