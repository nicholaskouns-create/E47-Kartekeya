# Observatory platform integration

The GitHub-hosted Observatory connects the existing City surfaces through additive iframe doorways and a source-backed instrument catalog.

Supabase project `gpkjvihkyectnenvnbng` supplies the existing public Route Packets API. The application can refresh these public packets on request, falling back to a snapshot of 10 explicitly public source artifacts fetched on 2026-10-13. Workspace/private rows, policies, and scopes are unchanged.

`observatory-registration.sql` is an idempotent additive registry entry to run only after live publication is verified. Registration does not independently certify the numerical models or grant agents authority. No new privileged API, schema, or authentication bypass is introduced.

Notion embeds the hosted app rather than executing source JavaScript. Drive holds a release archive and handoff. Linear tracks implementation evidence. Calendar integration exports a user-chosen session or opens a Google Calendar template; no meeting time is silently selected.
